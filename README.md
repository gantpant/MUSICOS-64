# MUSICOS64 — GitHub Pages

1. У `index.html` заміни `USERNAME` на свій GitHub username. Якщо репозиторій має іншу назву, зміни `MUSICOS64`.
2. Скопіюй `index.html`, `style.css` і `script.js` у корінь репозиторію сайту.
3. Зроби commit і push.
4. На GitHub відкрий **Settings → Pages**.
5. У **Build and deployment** вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`, потім натисни **Save**.
6. Дочекайся публікації — адресу GitHub Pages буде показано в розділі Pages.

Кнопка завантаження веде на GitHub Releases. Щоб вона завантажувала справжню систему, опублікуй ISO-файл як asset релізу.
